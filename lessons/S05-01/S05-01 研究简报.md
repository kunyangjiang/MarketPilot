## 3. 必须讲清的范围

按重叠矩阵第二节，本课首次讲清：

1. **回报**的定义（期末 − 期初 + 期间现金）÷ 期初。
2. **算术平均与几何平均**：回报连乘；+50% / −50%；回本表；两者回答的问题不同；有起伏时几何平均必低于算术平均。
3. **波动率（标准差）**：四步算法、方差、除以 n 与 n − 1、年化乘 √252 及其前提；近似式 G ≈ A − σ²/2 与「波动的拖累」；波动率对上下对称、不管顺序。
4. **最大回撤**：定义与公式；真实数据例（联储 H.10 日元）；与波动率衡量不同的东西；对时段与频率的依赖。
5. **正态分布**：钟形、两个参数、68 / 95 / 99.7 与 4σ、5σ 的尾部频率。
6. **肥尾**：公有领域数据计数 + Fama（1965）统计量 + Mandelbrot（1963）+ Cont（2001）综述；1987 年一个事实。
7. **波动聚集**：年份计数、20 日相邻比例；「大小有记忆，方向没有」；与肥尾的联系；两个后果。

**交给 S05-02 的术语表与符号**（S05-02 并行写作，直接使用）：

| 术语 | 英文 | 本课定义（课文原话或等价） | 符号 |
|---|---|---|---|
| 回报 | return | （期末价值 − 期初价值 + 期间收到的现金）÷ 期初价值 | r 或 R |
| 算术平均 | arithmetic mean | 各期回报相加除以期数；「随便挑一年，平均能拿到多少」；估计期望回报时用它 | 文字「算术平均」，不设符号 |
| 几何平均 | geometric mean | 使 (1 + G)ⁿ 等于实际总增长的 G；「一直拿着，钱实际每年按多少复利增长」 | G |
| 标准差 | standard deviation | 偏离平均值、平方、取平均、开平方 | σ（课文正文写「波动率」，公式里写「波动率²」） |
| 方差 | variance | 平方之后取的那个平均；标准差的平方 | σ² |
| 波动率 | volatility | 回报的标准差，通常按年报；日数据 × √252（一年约 252 个交易日），前提是各天回报互不相关 | σ |
| 最大回撤 | maximum drawdown | 从任一最高点跌到之后最低点的最大比例；回撤 = 1 − 当日价值 ÷ 此前最高价值 | 不设符号 |
| 中位数 | median | 排在正中间的那个结果，代表「典型」持有人 | — |
| 正态分布 | normal distribution（高斯分布） | 钟形曲线，由平均值和标准差完全确定；68.3% / 95.4% / 99.7% | — |
| 肥尾 | heavy tails / fat tails | 极端涨跌出现得比正态分布预测的频繁得多 | — |
| 波动聚集 | volatility clustering | 大的涨跌扎堆；涨跌的「大小」有记忆，「方向」没有 | — |

**给 S05-02 的注意事项**：本课没有讲「相关」「相关系数」「协方差」，波动聚集一节特意没用「自相关」一词（改写为「延续好几天」），以免抢 S05-02 的概念；本课说过「各天回报的方向互不相关」这一句日常用法，S05-02 定义相关系数时可回指。本课的「波动率」默认是年化的。

## 6. 开场形式

**数字谜题**（课程体系标为「数 / 互」）：一张假设的四年成绩单 +40%、+30%、−50%、+12%，算术平均正好 8%；$10,000 四年后只有 $10,192；第 2 年末买入的人亏掉一半。三句话都是真的，问题出在只看一个数。

- 全部是假设数字，不涉及真实产品，不需要核验史实。开场不用史实。
- 用小林作「被推荐的人」：小林没有任何买卖，持仓不变（仍只有北岭电池 600 股）。
- 与本批其他课的开场错开：S04-04 用真实公司案例，S05-02 用 Markowitz 的问题。与第三批（S03-06 原油负价格、S03-07 期权保险、S04-01～03）也不同。

备选（未用）：1987 年 10 月 19 日道指单日 22.6%。放弃原因：用它开场会把读者引到「崩盘史」，而学习目标的前半句（波动率、最大回撤）需要的是一串回报；它改放在肥尾一节作为一句史实。

### 8.1 数字模型一：四年成绩单（假设）

回报 0.40、0.30、−0.50、0.12。价值 10,000 → 14,000 → 18,200 → 9,100 → 10,192。算术平均 0.08；几何平均 1.0192^(1/4) − 1 = 0.004766（0.48%）；偏离 32、22、−58、4；平方和 4,888，÷4 = 1,222，√ = 34.957（35.0%）；÷3 = 1,629.3，√ = 40.365（40.4%）。最大回撤 1 − 9,100/18,200 = 50%；第 2 年末买入到第 4 年末 1 − 10,192/18,200 = 44.0%。近似式 0.08 − 0.1222/2 = 0.0189（1.9%）。甲 10,000 × 1.08⁴ = 13,604.89。

### 8.2 数字模型二：30 年对数正态（假设）

ln(1 + R) ~ N(m, s²)，s² = ln(1 + σ²/1.08²)，m = ln 1.08 − s²/2；E[(1 + R)³⁰] = 1.08³⁰ = 10.0627。中位数 = e^(30m)；P(30 年后 < 1) = Φ(−30m / (s√30))。模拟：mulberry32 种子 20261120，Box–Muller 余弦，每档 10,000 条，年末观察。

### 8.3 数字模型三：正态与 t₄ 的尾部

正态两侧：P(|Z| > 3) = 0.0026998，> 4 = 6.3342e−5，> 5 = 5.7330e−7；每万日 27.00 / 0.633 / 0.00573；4σ 一次约 62.6 年，5σ 一次约 6,922 年（每年 252 日）。t₄ 标准化（方差 2，阈值 k√2），两侧闭式 1 − t(t² + 6)/(t² + 4)^1.5：k = 3、4、5 时 0.013236、0.0048127、0.0021106，每万日 132.4 / 48.1 / 21.1。

### 8.4 数据计算：联储 H.10 日元（公有领域）

日元按美元算的价值 = 1 ÷ 汇率；6,735 个简单日回报（ND 跳过）。均值 −0.0048%，样本标准差 0.6202%，× √252 = 9.85%。超出 2 / 3 / 4 / 5σ：325 / 92 / 36 / 7（正态预测 306.4 / 18.18 / 0.427 / 0.0039）。最大一天 2008-10-24 +5.35%（8.64σ）。最大回撤 2011-10-28（75.72）→ 2026-07-29（163.86）53.79%；2026-11-13（159.93）52.65%；回本需 +116.4%。超 3σ 日按年见核验表 D09；20 日内相邻 59/92 = 64.1%，独立撒布近似 1 − (1 − 91/6,734)⁴⁰ = 42.0%。研究阶段另用对数回报算过一遍：3 / 4 / 5σ 为 89 / 34 / 7 天，结论相同；课文统一用简单回报，与「回报」的定义一致。

**加一张卡。** 理由：A 股的涨跌幅限制直接把日回报分布截在 ±10%（科创板 ±20%），改变「回报分布」的形状，正是本课主题；而且它带出一个有教学价值的推论：截掉的尾巴并没有消失，而是摊到后面几天，所以在这样的市场里只看日回报会让风险显得温和。
