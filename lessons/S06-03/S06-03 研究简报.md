## 3. 必须讲清的范围（首次讲清）

1. **信息不对称**（asymmetric information）、**逆向选择**（adverse selection）：用阿克洛夫的二手车例子，配逐轮缩小的数字推演。
2. 做市商面对的两类对手：**知情交易者**（informed trader）、**流动性交易者**（liquidity trader）；「知情」不等于内幕。
3. 格洛斯滕–米尔格罗姆式数字模型：卖价 = 「若下一笔是买单，资产的条件期望」；价差由流动性交易者替知情交易者付；价差 = 知情比例 × 价值差；成交使报价更新。
4. 价差的三个成分：**订单处理成本**、**存货成本**、**逆向选择成本**；用「价格会不会回去」区分；实证估计及其分歧。
5. 市场消失：流动性交易者对价格敏感时，价差变宽 → 流动性交易者离开 → 知情比例上升 → 价差再宽；门槛之上停止报价；与柠檬问题同构。
6. 什么让市场活下来：阿克洛夫的抵消制度；证券市场的披露与内幕交易禁令；更多流动性交易者。

## 8. 图、数字模型与交互

**图 1（二手车逐轮缩小，分步）**：阿克洛夫第 490–491 页例子，品质 0–2 均匀，买方效用系数 3/2；×$1,000 换成美元。逐轮：出价 $1,500 → $1,125 → $843.75 → $632.81（每轮 ×0.75）；肯卖比例 75%、56.25%、42.19%、31.64%；平均价值 $750、$562.50、$421.88、$316.41。原文结论：任何价格都无成交（p.491）。小题 1：出价 $1,800 → 平均 $900 → 愿付 $1,350。

**图 2（一百个来客，分步计数）**：V ∈ {$60, $40}，各 1/2；知情 α = 20%；流动性交易者买卖各半。好日 60 买 40 卖，坏日 40 买 60 卖；卖价 (60×60 + 40×40)/100 = $52，买价 $48。验算：知情者拿走 20 × $8 = $160；流动性买家多付 80 × $2 = $160。一般式：卖价 = $50 + $10α，价差 = $20α（即 GM 方程 (8)、(10) 取 π = 1/2）。第一笔买单后后验 0.6；再报价：卖价 (36×60 + 16×40)/52 ≈ $53.85，买价 $50。小题 2：α = 10% → $51 / $49。

**图 3（知情比例滑块，核心交互）**：「一定来」：s = $10α。「嫌贵会走」：流动性交易者上限 t ~ U[$0, $10]，零利润条件 α($10 − s) = (1 − α)(1 − s/$10)s，较小根 s = $10α/(1 − α)，α ≥ 50% 无解（停止报价）；留下比例 (1 − 2α)/(1 − α)。

| α | 一定来 | 嫌贵会走 | 留下 |
|---|---|---|---|
| 0 | 50 / 50 / 0 | 50 / 50 / 0 | 100% |
| 10% | 51 / 49 / 2 | 51.11 / 48.89 / 2.22 | 88.9% |
| 20% | 52 / 48 / 4 | 52.50 / 47.50 / 5.00 | 75% |
| 30% | 53 / 47 / 6 | 54.29 / 45.71 / 8.57 | 57.1% |
| 40% | 54 / 46 / 8 | 56.67 / 43.33 / 13.33 | 33.3% |
| 50% | 55 / 45 / 10 | 停止 | 0 |
| 60% | 56 / 44 / 12 | 停止 | 0 |

逐轮迭代 s(k+1) = $10α / [α + (1 − α)(1 − s(k)/$10)]：α = 20%：2.00 → 2.38 → 2.47 → 2.49 → 2.50；α = 50%：5 → 6.67 → 7.5 → 8 → 8.33 → … → 10。20% 时验算：平均每天 10 个知情买家 × $7.50 = $75 = 30 个流动性买家 × $2.50。

**独立复算**：`S06-03 数值核验.js` 全部重算并断言（通过 221，失败 0）；另对 α ≥ 50% 在 s ∈ [0, 9.99] 上逐点检验做市商利润为负；对小题 4 四个选项做比较静态检验。

**设计选择**：PO 要求「比例太高时市场停止报价」。GM 原文指出，流动性交易者完全无弹性时市场永不关门（p.74 脚注 2、p.84），所以本课保留两种设定的切换：「一定来」展示价差线性变宽但不关门，「嫌贵会走」展示关门。弹性设定用加法形式的上限（GM 用乘法形式的偏好参数），使阈值恰为 50%、数字可手算；这是本课简化，图方案与课文都写明门槛只属于这组假设。
