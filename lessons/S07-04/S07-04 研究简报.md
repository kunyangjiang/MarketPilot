## 3. 必须讲清的范围

1. **反馈、正反馈、负反馈**的定义，按「价格变动引出的交易与变动同向 / 反向」来定义。正负说方向，不说好坏；用「真消息 vs 偶然买单」说明同一种循环有时帮忙、有时添乱。
2. **循环的四个环节**：① 价格变动 → ② 某条规则看到它 → ③ 规则给出买卖 → ④ 交易改变价格 → 回到 ①。
3. **循环增益**：绕一圈回来，变动变成原来的几倍；正数为正反馈，负数为负反馈；正反馈增益小于 1 时自己衰减，大于 1 时要靠某一环断掉。
4. **一个负反馈循环**（价值型）和**一个正反馈循环**（趋势型）的逐日数字走查，同一个 $2 冲击。
5. **渠道**：规则直接看价格（趋势型、止损单 + / 止盈单 −）；价格改变账户（保证金追缴，+）；价格改变对冲比例（期权空头对冲与组合保险 +，期权多头对冲 −）；价格改变组合比例（再平衡 −）；价格与估值的距离（价值型 −）；价格被当成消息（一句指向 S07-03）。连续型规则与门槛型规则的区别。
6. **中断条件**按环节分四类：燃料耗尽（②）、能力用尽（③）、对面接得住（④）、交易暂停（时间）。能力用尽对两种循环意义相反。增益小于 1 的正反馈会自己衰减；负反馈天生会停，停在第二环认定的价格。
7. **两种循环同时在场**：一个 8 天的确定性例子（慢一拍、冲过头、摆幅缩小）；明确把参数空间留给 S07-05。
8. **类比的边界**：麦克风啸叫 / 空调温控；市场里的规则会变，人会预料循环（DSSW 1990，摘要层面）。
9. **术语表**（交给 S07-05、S08-04、S08-05、S10-03，定义须稳定）：

| 中文 | 英文 | 本课定义（课文用语） |
|---|---|---|
| 反馈 | feedback | 一件事的结果回过头来影响它自己的原因；在市场里，交易改变价格，价格又引出新的交易 |
| 正反馈 | positive feedback | 价格变动引出的交易与这次变动同方向，把价格推得更远：涨了引来买，跌了引来卖 |
| 负反馈 | negative feedback | 价格变动引出的交易与这次变动反方向，把价格拉回来：涨了引来卖，跌了引来买 |
| 环节 | link | 循环中的一步。至少四个：价格变动 → 某条规则看到它 → 规则给出买卖 → 交易改变价格 |
| 循环增益 | loop gain | 绕一圈回来，变动变成原来的几倍。正数为正反馈，负数为负反馈；正反馈增益小于 1 时自己衰减 |
| 中断条件 | （本课程用语，不附英文） | 让循环中某一环不再成立的条件；四类：燃料耗尽、能力用尽、对面接得住、交易暂停 |
| 止损单 | stop order / stop-loss order | 价格到达止损价时变成市价单的买卖指令（SEC 定义）；正反馈 |
| 止盈单 | take-profit order | 涨到某价位就卖、跌到某价位就买的挂单；负反馈 |
| 熔断机制 | market-wide circuit breakers | 按标普 500 单日跌幅分级暂停全市场交易 |
| 涨跌限制价带 | Limit Up-Limit Down | 单只股票的价格带；碰到价带 15 秒未回则暂停 5 分钟 |
| 连续型 / 门槛型规则 | — | 前者价格挪一点交易就变一点；后者价格碰到某个价位之前不交易，一碰到就是一整笔（课文用加粗的「连续」「有门槛」，不作为正式术语） |

**给 S07-05 的接口说明**：本课的价值型规则（按前一天收盘价与估值之差，每 $1 交易固定股数）与趋势型规则（按前一天涨跌，每 $1 交易固定股数）都是「流量」写法，与 S07-01 的「持仓」写法看的是同一个信号（课文第 64 行、第 108 行已说明）。S07-05 选定的模型若用不同写法，只需说明「看的信号相同」。本课没有随机项、没有参数空间，只有确定性的一条路径；增益大于 1 时摆动放大的边界检查只在数值脚本里，不进课文。

## 6. 开场形式

**数字谜题 / 思想实验**，不用史实。两个一模一样的市场，同一个 $2 冲击（20,000 股买单，无消息），四天后一个走回约 $50.13，一个走到约 $53.88。唯一的差别是站在对面的规则。全部写明「为这一课设的假设」。

选这个开场的理由：本课是「机」，核心是机制本身；用同一个冲击、两种结局，读者第一眼就看到「规则决定方向」。与 S07-01 的「五本账」（同一天、多种参与者）、S02-05 的 1923 年报纸、S05-04 的「$60 或 $40」都不同。

未采用：1987 年（归 S08-05）；外汇市场 1998 年 10 月 7 日美元兑日元下跌 11%（Osler 引言提及，但出处是她转述的市场评论，且本课不需要史实开场）。

## 8. 图、数字模型与交互

**模型（全部为假设）**：价格规则：除做市商以外净买入每 1,000 股，价格 +$0.10（λ = $0.0001/股）。冲击：第 0 天买 20,000 股，$50 → $52。价值型：每天 −a ×（前一天收盘 − $50）股。趋势型：每天 +b ×（前一天涨跌）股。

| 情形 | 参数 | 逐日收盘价 | 要点 |
|---|---|---|---|
| 负反馈 | a = 5,000，增益 λa = 0.5（方向相反，记 −0.5） | 51, 50.5, 50.25, 50.125 | 卖 10,000 / 5,000 / 2,500 / 1,250，累计趋于 20,000 |
| 负反馈，最多卖 12,000 股 | 同上 | 51, 50.80, 50.80… | 停在半路 |
| 小题 1：负反馈过猛 | a = 15,000，增益 −1.5 | 49, 50.5, 49.75, 50.125 | 冲过头、摆幅减半 |
| 正反馈 | b = 5,000，增益 +0.5 | 53, 53.5, 53.75, 53.875 | 极限 $54（$2/(1−0.5) = $4） |
| 正反馈，增益 1.5，最多持有 90,000 股 | b = 15,000 | 55, 59.5, 61, 61 | 买 30,000 / 45,000 / 15,000 / 0 |
| 小题 2：上限 60,000 股 | b = 15,000 | 55, 58, 58 | 买 30,000 / 30,000 / 0 |
| 两种同时在场 | a = b = 5,000 | 52, 51, 50, 49.5, 49.5, 49.75, 50, 50.125 | 峰值偏离 +2、−0.5、+0.125，每次 ×(−1/4) |
| 再平衡 | $100,000，60/40，股票 ±10% | — | 涨：$66,000 / $106,000 ≈ 62.3%，卖 $2,400；跌：买 $2,400 |

结论：**不设中国对照卡。**

- 本课讲的是循环的机制，规则（趋势、估值、再平衡、对冲）本身不随法域改变。
- 和中国差别最大的是「交易暂停」这一类中断条件：A 股有日内涨跌幅限制，2016 年初曾短暂实行指数熔断。这些对「暂停让时间停下，不让规则消失」是好例子，但：(1) 上交所《交易规则》在 2026 年有征求意见的修订（检索结果显示涉及风险警示股票涨跌幅比例），现行文本需要逐条核对；(2) 涨跌停对价格动态的影响（例如是否有「磁吸」）在学术上有争议，一张卡写不清。
- 建议：若 PO 认为有必要，在 S08-05（1987 年与之后的熔断设计）或 S10 的市场结构课里加一张「涨跌停与熔断」中国对照卡，届时读上交所 / 深交所交易规则原文与 2016 年 1 月 7 日的暂停熔断公告原文。本课不加。
