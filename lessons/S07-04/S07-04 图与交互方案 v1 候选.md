**本课三张图，都服务于「逐步写出每个环节」这个学习目标。** 图 1、图 2 用同一种版式（左边四格圆环、右边逐日表），读者在两张图之间只需要注意两处不同：圆环第二格读的是什么，第三格是买还是卖。版式相同是有意的：同一个 $2 冲击，换一条规则，循环的方向就反了。图 3 换成折线，因为它要看的是两种循环叠加后价格的形状（慢一拍、冲过头、摆幅缩小），逐日表看不出形状。

渠道一览放在正文表格里，不做成交互：它是归纳，不需要逐步揭示。「写出一个循环」的五个问题是正文列表，也不做成图。

与相邻课的图刻意不同：S07-01 是账卡与上下两层点线图；S05-04 是二叉树；S02-05 是价格滑块。本课的圆环 + 逐日表是本批唯一的「循环」版式。

## 共同的模型与数据

全部为本课教学假设，图顶注明「全部为假设」。不画任何真实价格、汇率、指数或基金数据；奥斯勒（S0704-R03）的结果只在正文转述，不画成图。

- 价格规则：除做市商以外所有人当天合计的净买入每 1,000 股，价格上调 $0.10；净卖出下调同样多。
- 冲击：第 0 天一笔 20,000 股的买单，价格 $50 → $52。
- 价值型：估值 $50；每天按前一天收盘价，每高于估值 $1 卖 5,000 股，每低于 $1 买 5,000 股。
- 趋势型：每天按前一天的涨跌，每涨 $1 买 5,000 股，每跌 $1 卖 5,000 股。
- 每一步的数字由 `S07-04 数值核验.js` 重算并断言。

## 图 1　负反馈循环：一天一天走回 $50

- **位置**：第 3 节「一个负反馈循环，一天一天走」，四个环节的文字链之后。
- **教学目的**：让读者亲手推着循环转四圈，看到每一圈第二环读出的差距变小、第三环卖得更少、第四环挪得更少；再看到第三环做不到时，循环停在半路。
- **类型**：分步循环图（四格圆环 + 逐日表）。
- **逐步内容**（读者点「下一步」，每点一次亮起圆环的一格，四格走完，表里添一行）：
  1. 第 1 天：差距 $2，卖 10,000 股、收 $51.00。
  2. 第 2 天：差距 $1，卖 5,000 股、收 $50.50。
  3. 第 3 天：差距 $0.50，卖 2,500 股、收 $50.25。
  4. 第 4 天：差距 $0.25，卖 1,250 股、收 $50.125。
  5. 表下一行：四天合计卖出 18,750 股，离第 0 天被买走的 20,000 股还差 1,250 股；圆环中央标「增益 −0.5」。
- **切换**「他们最多只能卖 12,000 股」：第 1 天卖 10,000 股、收 $51.00；第 2 天只卖 2,000 股、收 $50.80；第 3 天起卖 0 股，圆环第三格变灰，标「没有可卖的了」，价格停在 $50.80。
- **控件**：「上一步」「下一步」「重来」，切换按钮。不自动播放。
- **手机排版**：390 宽时圆环在上（直径约 220），逐日表在下，表只显示「天 / 卖出 / 收盘」三列；圆环每格的文字缩成两字标签（「高了」「读出」「卖出」「下调」），完整文字在 `aria-live` 区域。
- **静态版**：两张逐日表（无约束 / 最多卖 12,000 股），表上方一行四个环节的文字链。
- **可访问性**：每一步写进 `aria-live`，例如「第 2 天：价格比估值高 $1，价值型卖出 5,000 股，价格下调 $0.50，收在 $50.50」。按钮可键盘操作；当前格除颜色外加粗边框与「▶」标记。

## 图 2　正反馈循环：放大，还是失控

- **位置**：第 4 节「一个正反馈循环，一天一天走」，仓位上限一段之后。
- **教学目的**：看到增益 +0.5 时正反馈把 $2 放大成 $4 后自己衰减；增益 +1.5 时每圈变大，只能靠第三环断掉（仓位上限）才停。
- **类型**：分步循环图，版式与图 1 相同。
- **逐步内容**：
  - 切换「增益 +0.5」：第 1 天买 10,000 股、收 $53.00；第 2 天买 5,000 股、收 $53.50；第 3 天买 2,500 股、收 $53.75；第 4 天买 1,250 股、收 $53.875；表下写「最后走到 $54：$2 + $1 + $0.50 + … = $4」。
  - 切换「增益 +1.5（最多持有 90,000 股）」：第 1 天买 30,000 股、收 $55.00；第 2 天买 45,000 股、收 $59.50；第 3 天本该买 67,500 股，只能买 15,000 股、收 $61.00；第 4 天买 0 股、收 $61.00，圆环第三格变灰，标「仓位已满」。
- **控件**：同图 1。
- **手机排版**：同图 1；增益切换做成两个并排的分段按钮。
- **静态版**：两张逐日表。
- **可访问性**：同图 1；「仓位已满」用文字和图标表示，不只靠变灰。

## 图 3　两种循环同时在场：慢一拍，再冲过头

- **位置**：第 7 节「两种循环同时在场」，第 4 天一段之后。
- **教学目的**：看到两种规则同时在场时，第 1 天互相抵消、回归慢一拍，第 4 天冲过估值，然后来回摆、摆幅缩小。
- **类型**：分步折线图，横轴第 0 至第 8 天，纵轴价格，$50 处虚线标「估值」。
- **逐步内容**（每点一次推进一天，图下列出价值型 / 趋势型 / 合计）：
  - 第 1 天 −10,000 / +10,000，合计 0，收 $52.00
  - 第 2 天 −10,000 / 0，收 $51.00
  - 第 3 天 −5,000 / −5,000，收 $50.00
  - 第 4 天 0 / −5,000，收 $49.50（高亮「冲过估值」）
  - 第 5 天 +2,500 / −2,500，合计 0，收 $49.50
  - 第 6 天 +2,500 / 0，收 $49.75
  - 第 7 天 +1,250 / +1,250，收 $50.00
  - 第 8 天 0 / +1,250，收 $50.125（高亮「摆幅从 $2 缩到 $0.125」）
- **对照线**：浅灰色画出只有价值型时的路径：$52、$51、$50.50、$50.25、$50.125……
- **控件**：「上一步」「下一步」「重来」。不自动播放。
- **手机排版**：图宽占满，高约 240；逐日数字放在图下的单行卡片里，左右滑动切换日期的功能不做，只用按钮。
- **静态版**：九行表（第 0 至第 8 天：价值型、趋势型、合计、收盘价）。
- **可访问性**：每一步写进 `aria-live`，例如「第 4 天：价值型不交易，趋势型卖出 5,000 股，价格跌到 $49.50，低于估值」。折线点用不同形状区分「本路径」与「对照路径」，不只靠颜色。
