# S05-03 图与交互方案 v1 候选

内部文档，不进入发布目录 · 2026-11-20 · 对应《S05-03 课文 v1 候选》 · 数字由 `S05-03 数值核验.js` 复算并断言

本课三张图。本课是「机 / 思」课，图只放在三个需要「看见」的地方：同样的波动率可以有不同的来源（图 1）；期望回报只随 beta 变（图 2）；模型预测与数据的差距（图 3）。竞价的直觉、两种年景、因子暴露的算例都用正文和表格讲清，不另做图。

通用要求（三张图都适用）：
- 分步内容由读者点「下一步」推进，绝不自动播放；有「上一步」「重来」。
- 每张图都有静态版（表格），用于打印、PDF 与「减少动态效果」设置。
- 颜色之外另用文字标注区分两类数据（深色 / 浅色段旁直接写「跟着市场」「自己的」；预测 / 实际柱顶直接写数并加图例文字），色觉障碍读者不依赖颜色也能读。
- 按钮可用 Tab 聚焦、Enter / 空格触发；按钮组内可用左右方向键切换。
- 手机（宽 375px）：图宽 100%，左右各留 16px；按钮换行排列，每个按钮触控区不小于 44px；柱顶数字字号不小于 13px。
- 图里不出现任何真实指数、个股的价格或回报序列；图 3 只放论文报告的统计量（见数据来源）。

## 图 1　同样 30%，拆开不一样

- **教学目的**：让读者看到，两只波动率相同的股票，风险的来源可以完全不同；在持有很多只股票的人眼里，只有「跟着市场」的那一段还在。为下一节「期望回报只看 beta」做准备。
- **类型**：分步图（三步），两根并排的方差柱。
- **数据及来源**：全部是本课假设。市场组合波动率 20%（方差 400）；北岭电池 β = 1.4，超市股 β = 0.5；两只股票总波动率都是 30%（方差 900，沿用 S05-02 的设定）。跟着市场的部分 = β² × 400：北岭电池 784，超市股 100；自己的部分：北岭电池 116（约 10.77%），超市股 800（约 28.28%）。与市场的相关系数 = β × 20 ÷ 30：约 0.93、约 0.33。
- **逐步内容**：
  1. 第一步：两根等高的柱，柱顶写「900（波动率 30%）」，柱下写「北岭电池」「超市股」。每根柱分两段：深色段「跟着市场」784 / 100，浅色段「自己的」116 / 800，段内直接写数。
  2. 第二步：标题行出现「持有很多只股票之后」。浅色段缩到接近零（不做连续动画，直接切换到缩短后的状态），深色段不动；柱旁一行字「自己的部分在组合里互相抵消（上一课）」。
  3. 第三步：两根柱下方标出 β = 1.4、β = 0.5，以及「与市场的相关系数 约 0.93 / 约 0.33」。
- **手机排版**：两根柱上下排列改为左右并排保持不变（柱宽各 40%），段内数字放不下时移到柱右侧并用细线引出。
- **静态版**：课文第 3 节那张表（总方差、跟着市场的部分、自己的部分、与市场的相关系数）。
- **可访问性**：每一步的文字说明同时作为 `aria-live` 区域朗读；柱子有 `role="img"` 与完整的 `aria-label`（例如「北岭电池：总方差 900，跟着市场 784，自己的 116」）。

## 图 2　证券市场线

- **教学目的**：把 CAPM 的式子变成一条线；读者按 beta 的按钮，看期望回报怎样随 beta 直线上升，并看到两只波动率相同的股票落在线上不同的位置。
- **类型**：交互图（按钮切换），坐标图上一条直线与一个高亮点。
- **数据及来源**：本课假设。无风险利率 4%，市场风险溢价 5%。期望回报 = 4% + β × 5%：β = 0 → 4%；β = 0.5 → 6.5%；β = 1 → 9%；β = 1.4 → 11%；β = 2 → 14%。
- **逐步内容**：
  - 初始状态：横轴 beta（0 到 2，刻度 0.5），纵轴期望回报（0 到 15%，刻度 5%）；画出过（0，4%）、（1，9%）、（2，14%）的直线；右上角一行「无风险利率 4%，市场风险溢价 5%（假设）」。
  - 下方五个按钮：β = 0、0.5、1、1.4、2。按下一个，线上对应的点高亮，旁边写期望回报；β = 0.5 的点旁写「超市股」，β = 1.4 的点旁写「北岭电池」，两者旁边都有一行小字「波动率 30%」；β = 0 的点旁写「股票甲：期望回报 = 无风险利率」；β = 1 的点旁写「市场组合」。
  - 不自动轮播。
- **手机排版**：坐标图高 240px；按钮一行五个放不下时分两行；点的标签在窄屏改为显示在图下方的一行文字里。
- **静态版**：五行表（β、期望回报、对应的例子）。
- **可访问性**：按钮组 `role="radiogroup"`，左右方向键切换；切换后用 `aria-live` 朗读「beta 1.4，期望回报 11%，北岭电池」。

## 图 3　模型说的，和数据里的

- **教学目的**：用两组论文报告的统计量，直接对照 CAPM 的预测与实际平均回报：按 beta 分组时，线比模型平；按账面市值比分组时，平均回报大幅变化而 beta 几乎不变。
- **类型**：分步对比柱状图（两步），每步两组、每组两根柱（预测 / 实际）。
- **数据及来源**：Fama 与 French（2004，*Journal of Economic Perspectives* 18(3)）正文报告的统计量，登记为 S0503-R06（第 33 页、第 42 页）：
  - 第一步，按 beta 分组，1928—2003 年，十个市值加权组合：beta 最低一组，CAPM 预测每年 8.3%，实际 11.1%；beta 最高一组，预测 16.8%，实际 13.7%。
  - 第二步，按账面市值比分组，1963—2003 年（1963 年 7 月至 2003 年 12 月）：最低一组，预测 11.8%，实际 10.1%；最高一组，预测 11.2%，实际 16.7%。
  - 这些是论文对 CRSP 数据计算结果的文字报告，课文与图只转述这八个数，不复制论文的图，不画任何回报序列。CRSP 原始数据「仅作研究、不上网页」，本课未使用。
- **逐步内容**：
  1. 第一步标题「按 beta 分组，1928—2003 年」：左组「beta 最低」，浅色柱（预测）8.3%、深色柱（实际）11.1%；右组「beta 最高」，预测 16.8%、实际 13.7%。柱下一行字「低 beta 赚得比预测多，高 beta 赚得比预测少」。
  2. 第二步标题「按账面市值比分组，1963—2003 年」：左组「账面市值比最低（beta 最高）」，预测 11.8%、实际 10.1%；右组「账面市值比最高（beta 0.98）」，预测 11.2%、实际 16.7%。柱下一行字「beta 几乎一样，平均回报差了 6.6 个百分点」。
  - 图下注：「数字为 Fama 与 French 2004 年综述报告的美国股票组合年化平均回报与 CAPM 预测值」。
- **手机排版**：每组两根柱横向排列，两组上下排列；纵轴统一 0 到 18%，两步用同一刻度，便于比较。
- **静态版**：四行表（分组方式、组别、CAPM 预测、实际）。
- **可访问性**：每根柱 `aria-label` 写全「beta 最低一组，CAPM 预测 8.3%」；步骤说明 `aria-live` 朗读。

## 不做成图的部分（说明）

- 竞价的例子（$100 与 $103.85）、两种年景表、两因子模型的表，都已经在课文里以短算式或表格出现，再做成图不增加信息。
- 不做「beta 回归散点图」：需要回报序列，按数据授权规则不上网页；用模拟数据画又容易被误读为真实结果。
- 不放照片。
