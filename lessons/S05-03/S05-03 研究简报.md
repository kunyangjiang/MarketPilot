## 3. 必须讲清的范围

1. 补偿通过价格实现（同样的期望现金流，价格低 ↔ 期望回报高）。
2. 直觉层：可以几乎零成本分散的风险，在竞争中拿不到补偿（竞价例子）；分散不掉的风险要有补偿。直觉的前提就是模型的假设。
3. CAPM：出处（Sharpe 1964、Lintner 1965）、四条假设、夏普本人对假设的评价、三步推理（同一风险组合 → 市场组合 → 只看跟着市场的部分）、市场组合的理论范围。
4. beta 的定义与通俗解释；市场暴露（首次）；beta 与相关系数的关系；同样总波动、不同 beta 的方差拆分。
5. CAPM 方程、市场风险溢价、证券市场线；beta 为 0 得无风险利率；指向第 4 阶段折现率与戴尔案。
6. 事前与事后：两种年景表；beta 是事前量；事后平均对事前期望的估计误差（8.3%，标准误差 2.4%，3.5%–13.1%）。
7. 证据层一：beta 与平均回报的关系太平（BJS 1972；FF2004 1928–2003；FF1992 1963–1990 几乎平）；布莱克版；借钱约束的解释（Frazzini–Pedersen 工作论文）；市场代用品问题。
8. 证据层二：规模、账面市值比（价值 / 成长）、其他价格比率；价格比率为什么携带期望回报信息；国际证据；动量。
9. 多因子模型：三因子定义、因子暴露（首次）、两因子教学算例；因子溢价的实际均值与不确定性；动量因子、五因子（工作论文）；模型由实证驱动的缺点。
10. 风险补偿还是定价错误：风险派（ICAPM、FF1993 前提、FF1992 困境）、定价错误派（LSV 工作论文）、约束派（FP）；争论为何难以了结（检验需要预期回报模型）；资本成本用途下的实用看法。

## 8. 图、数字模型与交互

**模型参数（全部是本课假设，写明「假设」）**
- 竞价例子：股票甲一年后平均 $108，β = 0；一年期国债 4%。买家一要求 8% → $108 ÷ 1.08 = $100；买家二要求 4% → $108 ÷ 1.04 ≈ $103.85。
- 市场组合波动率 20%（方差 400）。北岭电池 β = 1.4、超市股 β = 0.5，总波动率都是 30%（沿用 S05-02）。跟着市场：784、100；自己：116（约 10.77%）、800（约 28.28%）；相关系数 = β × 20 ÷ 30 ≈ 0.93、0.33。
- CAPM：无风险利率 4%、市场风险溢价 5%；β = 0 / 0.5 / 1 / 1.4 / 2 → 4% / 6.5% / 9% / 11% / 14%。小题 2：β = 1.2 → 10%（干扰项 14.8% = 4% + 1.2 × 9%；6% = 4% + 0.4 × 5%）。
- 两种年景：市场超额 +25 / −15 各半 → 平均 5、标准差 20；市场回报 +29% / −11%；北岭 +39% / −17%（平均 11%）；超市 +16.5% / −3.5%（平均 6.5%）。
- 两因子算例：市场溢价 5%、价值溢价 3%；β = 1.0，价值暴露 0.8 / −0.2 → 11.4% / 8.4%（CAPM 都是 9%）。小题 4：β = 1.2、价值暴露 0.5 → 11.5%（干扰项 10%、12.5%、7.5%）。
