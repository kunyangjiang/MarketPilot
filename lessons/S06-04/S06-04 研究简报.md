## 3. 必须讲清的范围（首次讲清）

1. **行为偏差**的含义（方向固定、可重复、事先可预言方向），与偶然看错的区别；证据为什么要用真实交易记录。
2. **三项有交易数据支持的行为规律**（矩阵允许两三项，本课用三项，因为第三项「注意力」恰好给出「错误相关」的机制来源）：
   - 处置效应（Odean 1998）：PGR / PLR 的构造、为何不能只数卖出次数、主要数字、12 月的税的例外、对替代解释的排查、事后回报；
   - 过度交易（Barber–Odean 2000）：换手五分组，毛回报相近、净回报相差约 7 个百分点；对 GS 理性预测的检验；过度自信作为作者解释；
   - 注意力驱动的买入（Barber–Odean 2008）：买与卖的搜索不对称；买卖失衡；成交量、前一天极端回报、新闻三种迹象；机构相反。
3. **证据强度与边界**：真实记录、大样本、三家券商；美国、1987–1999、主要是折扣券商；平均倾向；直接证明的是自损而非价格错误；心理原因有争议。
4. **从个体偏差到价格偏离缺的那一步**：错误要相关（教学模型 + Barber–Odean–Zhu 2009 的 73% / 75%）；套利要受限（只点出，一句回顾 S03-04，展开留 S08-03）。来源：Barber–Odean–Zhu 2009 第 548–549 页明确列出两个条件。
5. **异象在发表后衰减**（McLean–Pontiff 2016）：三种来历对发表后的不同预测；26% / 58% / 32%；未降到零；越赚钱、越易套利降得越多；成交与卖空上升；作者的解读与边界。

## 8. 图、数字模型与交互

**图 1（PGR 与 PLR，分步柱图）**：论文统计量（Odean 1998 表 I），可上网页（只是论文报告的统计量，不是券商账户数据本身）。全年 13,883 / 79,658 / 11,930 / 110,348 → PGR 0.1484、PLR 0.0976；12 月 866 / 7,131 / 1,555 / 10,604 → 0.1083、0.1279；1–11 月由全年减 12 月：13,017 / 72,527 / 10,375 / 99,744 → 0.1522、0.0942，与表 I 的 0.152、0.094 一致（脚本 A 组独立复算）。

**图 2（教学模型：独立的错误抵消，相关的错误不抵消）**：
- 假设：N 位投资者，每人估值误差的标准差 σ = 20%；任意两人误差的相关系数 ρ 相同；每人买卖数量相同，价格 = 估值的平均；没有其他交易者。
- 价格偏离的标准差 = σ × √［1/N +（1 − 1/N）ρ］（与 S05-02 的分散公式同一算式）。
- N = 10,000：ρ = 0 → 0.20%；0.01 → 2.01%；0.1 → 6.33%；0.5 → 14.14%。ρ = 0.1 时 N = 100 → 6.60%，N → ∞ → 6.32%。ρ = 0 时 N = 100 → 2.00%。
- 小题 2：ρ = 0.04，N = 1 万与 100 万都约 4.00%；ρ = 0 时 0.20% 与 0.02%。
- 独立复算：脚本里用固定种子的蒙特卡洛（共同因子 + 个人因子构造相关误差）重算 N = 1,000 时 ρ = 0、0.1 的偏离标准差，与封闭解的相对误差在 5% 以内（D 组）。
- 「加入不受限制的套利者」开关只作定性展示（偏离缩回接近 0），不给数字，避免展开套利限制。

**小题数的理由（3 道）**：本课有三块各自需要读者动手检验的内容——PGR / PLR 为什么不能用卖出次数代替（规律一的方法核心）；相关误差为什么不随人数消失（「缺的那一步」的核心）；三种来历怎样从发表前后的衰减中被区分（异象衰减的逻辑核心）。规律二、三是对统计结果的阅读，出题只会变成记数字，故不设。

## 10. 中国对照的必要性

结论：**不加**。

- 本课的规律都来自美国券商数据。A 股的对照最有教学价值的是「个人投资者在交易中的占比」，它决定了相关错误的分量。上交所《统计年鉴》有投资者结构的正式统计，但本次两卷年鉴 PDF 都超过工具可读的大小上限（WebFetch 报 10 MB 上限），未能读到具体表格与口径；按规则不能用二手转述代替。
- Barber–Odean 2008 转述过 Seasholes 与 Wu 关于上交所涨停次日个人投资者净买入的研究，但那是对一篇未读论文的转述，而且不是证监会或交易所的正式文件，不符合中国对照卡的来源要求。
- 课文没有一处规则在中美之间不同，强行加卡没有教学价值。若 PO 希望加「A 股个人投资者交易占比」卡，需要允许下载上交所年鉴全卷 PDF（约 10 MB 以上）后再核。
