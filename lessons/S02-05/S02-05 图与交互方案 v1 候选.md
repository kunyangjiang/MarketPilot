## 图 1：钱和股票在哪里（第 2 节「融资买入」模式；第 4 节「卖空」模式，课文标为「图 1，续」）

- **教学目的：** 回答核心问题「融资买入和卖空，钱与股票怎样流动」；让读者看到镜像：融资买入借钱、押股票；卖空借股票、押钱。
- **类型：** 分步图。同一组件两处出现，默认模式不同；顶部有「融资买入」「卖空」切换。读者点「下一步 / 上一步」推进。
- **版式：** 四个方框：投资者账户（小林 / 周岚）、券商、市场上的对手（卖方 / 买方）、出借方（只在卖空模式亮起）。每个方框内有「钱」「股票」两格。实线箭头 = 钱，虚线箭头 = 股票；箭头旁都有文字标签，不只靠线型与颜色区分。

**融资买入模式（5 步，标「推演」）**

| 步 | 画面 | 账户（钱 / 股票 / 欠款 / 权益） |
|---|---|---|
| 1 | 小林的保证金账户 | $10,000 / 0 / 0 / $10,000 |
| 2 | 券商借给他 $10,000 | $20,000 / 0 / $10,000 / $10,000 |

| 5 | 一览：市值 $20,000，欠款 $10,000，权益 $10,000（50%）；30 天利息 $65.75 | — |

**卖空模式（6 步）**

| 步 | 画面 | 周岚账户（现金 / 欠股） |
|---|---|---|
| 1 | 下单「卖空 200 股」；券商确认可借（一个勾，标「locate：有合理理由相信能借到」） | 0 / 0 |
| 2 | 买方付 $10,000 | $10,000（锁住）/ 欠 200 股 |

## 图 2：价格线——什么时候被追缴（第 5 节；融资模式与第 2 节的算例对应）

- **教学目的：** 让读者自己找到追缴线，看到「融资买入怕跌、卖空怕涨」，以及卖空的追缴线离起点更近、亏损没有上限。
- **类型：** 交互计算。价格滑块 $10–$100，步长 $0.50，初值 $50；模式切换「融资买入（推演中的小林）」「卖空（周岚）」。
- **显示：** 价格轴标出起点 $50、追缴线（融资 $33.33 / 卖空 $57.69）、权益归零价（融资 $25 / 卖空 $75）；三个数字：市值、权益、维持要求；状态标签「正常」「追缴：差 $___」「权益为负：倒欠 $___」；追缴状态下多一行「不补钱的话，要卖出（或回补）约 ___ 股」。
- **开关（默认关）：** 融资模式「券商要求 30%」（追缴线 $35.71）；卖空模式「扣除 30 天借券费与股息替代款」（追缴线 $57.41）。
- **计算规则（与数值脚本相同）：**
  - 融资：权益 = 400P − 10,000；要求 = m × 400P（m = 25% 或 30%）；需卖股数 = ceil(缺口 ÷ (m × P))。
  - 卖空：权益 = C − 200P（C = 15,000，开关打开时 14,925.34）；要求 = max(1,000, 30% × 200P)；需回补股数 = ceil(缺口 ÷ (30% × P))。
- **固定小字：** 「教学模型：利率、费率、要求比例均为假设；真实券商的要求可能更高，也可能不通知就卖出。」
- **手机：** 滑块全宽；三个数字纵排；价格轴只留三个刻度标签。
- **可访问性：** 滑块支持方向键（±$0.50）与 PageUp / PageDown（±$5）；状态变化用文字朗读，「追缴」不只靠变色。
