## 生产流水线

每课依次产出五件交付物，放在 `lessons/<课号>/`：

1. `<课号> 课文 v1 候选.md`（标记沿用 S01 / S02 课文，可被 `site/tools/lesson-build/md2html.js` 解析）
2. `<课号> 图与交互方案 v1 候选.md`
3. `<课号> 数值核验.js`（读取课文，断言课文中出现的数字）
4. `<课号> 核验记录.md`（含「课文论断与来源对照」一节）
5. `<课号> 学术审阅包.md`（B 节逐字收录课文）

完成后运行自动检查，失败项直接修复并重跑，全部通过才算完成：

```
node "lessons/工具/课程自动检查.js" S02-05 S03-01 S03-02
```

自动检查的项目：五件交付物齐全；正文 5,000–8,000 字（`lessons/工具/正文字数.js`，口径与 S01 各课一致：中国对照计入）；数值脚本通过且读取课文；课文标记可解析；正文没有核验标记、开发痕迹和弃用词；审阅包逐字收录课文、字数一致；课文中的图都在图与交互方案里；每道小题都有提示与答案；课文论断没有 ☐，引用的来源编号都已登记。

机器检查不到的：术语与课程体系是否一致、虚构设定是否一致（对照《北岭电池 统一案例设定表》）、前后课依赖、图表数字与课文是否一致。这些由批次负责人在每轮结束时人工复核。
