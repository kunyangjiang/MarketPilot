## 1. 核心问题与学习目标（照录课程体系 v1.0 第 2 节）

- **核心问题**：观察他人的行动怎样取代了自己的信息？
- **学习目标**：能用抽球实验说明信息瀑布如何形成，并说出这个模型在价格可变的市场里的局限。
- **课程体系第 7.3 节待核项**：信息瀑布模型及其在价格可变时的局限 · 原始论文 · ☐（本简报第 9 节处理）。

## 3. 必须讲清的范围（本课首次讲清）

1. **私人信号**（private signal）与**贝叶斯法则 / 贝叶斯更新**（Bayes' rule / Bayesian updating）：只用计数法，不写公式。对称罐子里「一个浅球抵一个深球，净差决定判断」（安德森与霍尔特 1997 第 850–851 页明说这对应一个简单的计数启发式）。
2. **信息瀑布**（informational cascade）：BHW 1992 的定义（摘要与第 1000 页的正式定义）；形成条件（净差到 2）；为什么会延续（第 994 页）。
3. **抽球实验**：安德森与霍尔特 1997 的设计与结果。
4. **羊群行为**（herd behavior）：班纳吉 1992 的定义；与瀑布的区别（埃弗里与泽姆斯基：简单模型里两者相同，复杂模型里可以有羊群行为而无瀑布）。
5. **反向瀑布**（reverse cascade）与错误瀑布的概率。
6. **瀑布的脆弱性**：BHW 第 III 节结果 3。
7. **价格可变时的局限**：价格调整让瀑布无法形成（埃弗里与泽姆斯基的例子与命题 2、4）；实验证据（西普里亚尼与瓜里诺）；羊群行为在什么条件下回来（事件不确定、构成不确定、交易成本、事先定价）。

## 6. 开场形式

**一个只有一百个人的思想实验（班纳吉的餐馆例子）**。理由：
- 已核验：班纳吉 1992 第 798–799 页原文，脚注 5 注明例子来自匿名审稿人（✔）。
- 它在几百字内让读者看到全课的核心悖论：99 条消息指向乙，100 人全进甲，没有人犯傻。
- 与前后课不同：S07-02 以读者亲手玩数字游戏开场；S07-01 以同一价格下五本账开场；S06-03 以做市商面对一个爽快的买家开场。本课以「一个小世界的故事」开场，主体交互放到第 3 节。

**图 3 让价格动起来**：同样三组球；价格 = $40 + $20 × 甲罐可能性。价格会动时的决定与最后价格：情景一 买 买 卖 买 买 卖 买 买 → 约 $58.82；情景二 买 买 卖 卖 卖 卖 卖 买 → $44；情景三 买 卖 买 买 卖 买 卖 买 → $56。

**数字模型与独立复算**（研究阶段用 node 独立算过，生产阶段并入《S07-03 数值核验.js》）：
- 净差 d 时甲罐可能性 2^d / (2^d + 1)：d = 1 → 0.6667；2 → 0.8；3 → 0.8889；4 → 0.9412；与直接用贝叶斯法则 q^n(1−q)^m 的比较对 n、m ≤ 8 全部一致。
- 错误瀑布（按安德森与霍尔特的打平规则）：(1−q)² / (q² + (1−q)²)；q = 2/3 → 0.2；q = 0.6 → 0.3077；q = 0.75 → 0.1；q = 0.9 → 0.0122。另用 400 步的精确概率递推复核 q = 2/3 时为 0.2。
- 每两人仍未形成瀑布的概率乘 2q(1−q) = 4/9：2、4、6、8、10 人后为 44.44%、19.75%、8.78%、3.90%、1.73%。
- 对照 BHW 原文（打平掷硬币）：q = 2/3 时两人后上 / 无 / 下 = 0.3889 / 0.2222 / 0.3889，长期正确瀑布 5/7 ≈ 0.714（BHW 式 (1)–(3)）；q → 1/2 时十人后未成瀑布 (1/4)^5 = 0.098% < 0.1%（BHW 第 997–998 页）。课文只用后者，并说明本课打平规则不同。
- 价格：d = −3…4 → $42.22、$44、$46.67、$50、$53.33、$56、$57.78、$58.82。
- 穷举 2^8 种球序列：价格会动时无人与自己的球反着做；价格固定时存在。

## 10. 中国对照的必要性

不加。本课讲的是一个一般的信息机制与一个理论 / 实验结论，不涉及美国特有的规则或制度。课文没有任何以美国制度为前提的论断（价格版是教学模型，不是某个交易所的规则）。新股定价、涨跌停等中国市场制度可能与「价格能否自由调整」有关，但要讨论需要实证文献支持，强行加入会超出本课范围，也没有可靠的一手材料能在一张卡里讲清；不提议单列一课。
