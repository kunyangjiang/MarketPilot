## 1. 核心问题与学习目标（照录课程体系 v1.0）

- **标题**：不预测股票涨跌，怎么可能算出一份期权值多少钱？
- **核心问题**：能被复制的东西为什么必须和复制品同价？股价变动之后，复制组合需要怎样调整？
- **学习目标**：能在明确的无套利假设下，用一期二叉树以股票加借款复制一份期权；说明在多期情形下对冲比例为何随股价变化；并区分"对冲一个已持有的期权头寸"与"动态复制一份保护性看跌期权"，解释两者的买卖方向为什么可能相反
- **形式**：数 【修正】
- **修正要点**（第 2 节）：第 0 部分模型假设先说清、结尾回顾哪一条最易失效；第 1 部分一期无套利复制，结论与上涨概率无关；第 2 部分多期动态对冲（定性），明说是一期推不出的新内容，只用两期树展示 delta 变化方向，不算完整两期价格；第 3 部分方向取决于头寸，方向讲清之后再给 gamma 为正 / 为负；第 4 部分三行对照表（持有看跌并对冲、卖出看跌并对冲、合成保护性看跌），说明对理解 1987 年为什么关键。第 1–3 部分篇幅约 3 : 2 : 2。不出现 Black–Scholes 公式。

## 3. 必须讲清的范围

1. 第 0 部分：四条假设（两种结果；按无风险利率借贷；自由买卖与卖空、无交易成本；及时调整、不跳过调整点）＋两处简化（不分红、欧式）。
2. 第 1 部分：一期复制看涨（0.5 股 − $19.80 = $5.20）；无套利论证（偏高、偏低两个方向）；与概率无关、概率经由股价间接起作用；幅度才起作用；delta / 对冲比例术语；看跌复制（为第 4 部分准备）。
3. 第 2 部分：两期树节点 delta（0.57 → 0.92 / 0）；不调整会对不上；动态复制与动态对冲两个术语；自融资。
4. 第 3 部分：多头对冲逆势、空头对冲顺势（看涨与看跌都一样）；否定笼统的「卖方 / 做市商追涨杀跌」；方向讲完后给 gamma；权利金正好付对冲净成本。
5. 第 4 部分：抵消 vs 制造；三行表；合成多头 = 空头对冲者的交易；合成复制没有对应的对手方；组合保险定义（Brady 报告第 7 页）。
6. 结尾：逐条回顾假设，「不跳过调整点」最易失效且后果最重；1987-10-19 一句指向 S08-05。

## 8. 图、数字模型与交互

**模型参数（全部是本课假设）**：S₀ = $50；每期（三个月）涨 20% 或跌 20%；每期利率 1%（单利按期复合，R = 1.01）；行权价 K = $50；欧式；不分红。

**一期**：看涨 Δ = 0.5，借 B = 20 / 1.01 = 19.80198，C = 5.19802；看跌 Δ = −0.5，存 30 / 1.01 = 29.70297，P = 4.70297。自检：C − P = 0.49505 = 50 − 50 / 1.01。套利：$6 → 0.80198；$4.50 → 0.69802；$5.50 → 0.30198。$55 / $45 时 C = 25 − 22.5 / 1.01 = 2.72277。

**两期**（期权六个月到期）：股价 72 / 48 / 32。
- 看涨：Δu = 22 / 24 = 0.91667，Δd = 0，Cu = 11.43564，Cd = 0，Δ₀ = 0.57178。
- 看跌：Δu = −0.08333，Δd = −1，Pu = 0.94059，Pd = 9.50495，Δ₀ = −0.42822。
- 每个节点上看涨 Δ − 看跌 Δ = 1（脚本自检，课文不写）。
- 每张合约（100 股）：57.2 → 91.7（+34.5）或 0（−57.2）；看跌 42.8 → 8.3（−34.5）或 100（+57.2）。
- 不调整的偏差：静态组合 0.57178 股、借 22.64484（课文不写这两个数）；到期 $72 时 18.068（少 3.932）；$48 时 4.346；$32 时 −4.803。
- 合成保护性看跌：起点 0.57178 股＋现金；$40 节点全部现金 49.50495，到期两种结果都正好 $50。
- 跳空：若从 $50 直接跳到 $32 并停在那里，合成者的组合价值 44.93（t = 1）< 50 / 1.01 = 49.505（脚本断言，课文只写「底就破了」）。
