# S05-04 图与交互方案 v1 候选

内部文档，不进入发布目录 · 2026-11-20 · 对应《S05-04 课文 v1 候选》

## 总原则

- 三张图，各管一个教学目标：图 1 管「复制与概率无关」，图 2 管「delta 随股价变化」，图 3 管「方向取决于抵消还是制造」。
- 全部分步或按钮切换，由读者点击推进，**绝不自动播放**；每张图都有静态版（一张完整的终态图加文字表），静态版里的信息与交互版完全相同。
- 尊重 `prefers-reduced-motion`：开启时取消所有过渡动画，直接切换。
- 键盘：「上一步」「下一步」「重来」与切换按钮都是 `<button>`，可 Tab 聚焦、空格 / 回车触发；滑块是 `<input type="range">`，方向键每次 5 个百分点。
- 每张图的固定小字：「教学模型：股价、涨跌幅度与利率都是假设」。

## 数据使用限制

全部数字来自本课教学模型（股价 $50，每三个月涨 20% 或跌 20%，利率每三个月 1%，行权价 $50，欧式，不分红），可上网页。不使用任何真实价格或指数序列。图中**不出现两期期权价格**（课程体系第 8 节：只展示方向，不算完整两期价格）。

## 图 1　一期复制，一步一步搭（分步图 + 一个滑块）

- **教学目的**：让读者亲眼看到半股股票加借款在两种结果下都与看涨期权逐格相同，并通过概率滑块看到「平均到期值」随概率变、复制成本不变。
- **类型**：分步树状图，6 步。
- **数据**：S₀ = $50；$60 / $40；看涨到期值 $10 / $0；半股 $30 / $20；借款 −$20 / −$20；今天借到 $20 ÷ 1.01 ≈ $19.80；成本 $25 − $19.80 = $5.20。
- **逐步内容**：
  1. 股价树：$50 分成 $60 与 $40。
  2. 看涨期权到期值：$10 与 $0。
  3. 加入半股股票：$30 与 $20（标注「起伏 $10，与期权相同」）。
  4. 加入借款：两端各 −$20；组合合计 $10 与 $0，与期权一格一格对齐（对齐处高亮）。
  5. 今天的成本：$25 − $19.80 = $5.20。
  6. 「上涨概率」滑块（10% 到 90%，步长 5%，初值 50%）：显示「按这个概率算出的平均到期值」= 概率 × $10（90% 时 $9，30% 时 $3），旁边的「复制成本」始终是 $5.20，不随滑块动。
- **手机排版**：树纵向排列（今天在上，三个月后在下，两个结果左右并排）；数字表格放在树下方；滑块全宽。
- **静态版**：一张完整的树（第 5 步终态）加一行文字「上涨概率 90% 时平均到期值 $9，30% 时 $3，复制成本都是 $5.20」。
- **可访问性**：每一步变化以文字写在图下方的说明区（`aria-live="polite"`）；对齐高亮同时用加粗边框，不只靠颜色。

## 图 2　两期树：每个节点该持有多少股（分步图）

- **教学目的**：展示 delta 在上涨后变大、下跌后变小，复制组合必须调整；这是一期模型推不出的新内容。
- **类型**：分步树状图，6 步，含看涨 / 看跌切换。
- **数据**：股价 $50 → $60 / $40 → $72 / $48 / $32；看涨到期值 $22 / $0 / $0；delta：$60 节点 0.92（$22 ÷ $24），$40 节点 0，起点约 0.57；看跌 delta：约 −0.08、−1、约 −0.43。
- **逐步内容**：
  1. 两期股价树。
  2. 到期时看涨期权的值：$22 / $0 / $0。
  3. $60 节点：delta 0.92（标注「$22 ÷ $24」）。
  4. $40 节点：delta 0（标注「两个到期值都是 0」）。
  5. 起点：delta 约 0.57；上涨分支箭头标「多持有」，下跌分支标「少持有」。
  6. 切换到看跌期权：−0.43、−0.08、−1（$40 节点标注「$48、$32 都低于行权价」）。
- **手机排版**：树横向放不下时改为纵向三层；节点标签用两行（股价一行，delta 一行）。
- **静态版**：完整的两期树，每个节点标股价与看涨 / 看跌两个 delta，下附文字「涨了要多持有，跌了要少持有；看跌期权方向相同，数值都比看涨小 1」。（「小 1」只在图的静态版注释里出现，用于读者对照两组数，不作为定理讲解。）
- **可访问性**：树同时提供一个等价的数据表（节点 | 股价 | 看涨 delta | 看跌 delta），屏幕阅读器读表。

## 图 3　同一次涨跌，三种人怎样交易（按钮切换）

- **教学目的**：课程体系第 6.4 节规定的「两期树的方向示意」：读者看到股价上涨或下跌后，期权多头对冲者、空头对冲者与合成复制者三者的买卖方向，理解「抵消」与「制造」符号相反。
- **类型**：两个按钮（「股价涨到 $60」「股价跌到 $40」）切换的三行对照卡；另有一个「看涨 / 看跌」切换（默认看跌，与课文的三行表一致）。
- **数据**（按 1 张合约 = 100 股，保留一位小数）：
  - 看跌期权，跌到 $40：持有看跌并对冲者 42.8 → 100 股，买入 57.2 股；卖出看跌并对冲者卖空 42.8 → 100 股，卖出 57.2 股；合成保护性看跌者 57.2 → 0 股，卖出 57.2 股。
  - 看跌期权，涨到 $60：持有看跌并对冲者 42.8 → 8.3 股，卖出 34.5 股；卖出看跌并对冲者卖空 42.8 → 8.3 股，买入 34.5 股；合成者 57.2 → 91.7 股，买入 34.5 股。
  - 看涨期权，涨到 $60：持有看涨并对冲者卖空 57.2 → 91.7 股，卖出 34.5 股；卖出看涨并对冲者 57.2 → 91.7 股，买入 34.5 股。
  - 看涨期权，跌到 $40：持有看涨并对冲者买回 57.2 股；卖出看涨并对冲者卖出 57.2 股。
  - （看涨模式下第三行显示「合成看涨期权多头：交易与卖出看涨并对冲者相同」。）
- **逐步内容**：读者先选涨或跌，三行依次亮起（点「下一行」推进，不自动）；每行显示「目的：抵消 / 制造」「起点股数」「之后股数」「交易：买 / 卖 若干股」，买入用向上箭头加文字「买入」，卖出用向下箭头加文字「卖出」；最后一步在第二、三行之间画等号「交易相同」。
- **手机排版**：三行改为上下三张卡片；按钮固定在卡片上方。
- **静态版**：课文中的三行表（看跌、下跌），外加一张同样结构的「上涨」表。
- **可访问性**：买卖方向用文字和箭头双重表示，不只靠红绿色；色盲安全配色。
