## 图 1　三层信息，一层套一层

- **教学目的**：说清三种形式的区别只在于「信息集合」大小，并且一层套一层：强式成立则半强式、弱式成立，反之不成立。
- **类型**：同心圆分步图。
- **数据及来源**：无数值。三层定义与各层判断出自 Fama（1970）p.383、p.388、pp.414–416（S0602-R01）；罗伯茨的区分见 p.383 脚注 1。
- **逐步内容**：
  1. 只亮最内圈「过去的价格和回报」，旁注「弱式：看走势图赚不到超出正常的回报」。
  2. 亮中间一圈「所有明显公开的信息：盈利公告、分拆、新股发行……」，旁注「半强式」。
  3. 亮最外圈「全部信息，包括独占的信息」，旁注「强式」。
  4. 三圈旁各标法马 1970 年的判断：弱式「证据最多，大体支持」；半强式「大体支持」；强式「找到两个例外：交易所专营商、公司内部人」。
- **手机排版**：同心圆缩为三层嵌套的圆角矩形，竖向排列，判断文字放在矩形下方，不与图形重叠。
- **静态版**：第 4 步完整画面，下附三行表（形式｜信息集合｜1970 年的判断）。
- **可访问性**：「下一步」「上一步」按钮可用 Tab 聚焦、Enter 触发；每步更新一段 aria-live 文字，读出新亮出的那一层和旁注。

## 图 2　同一个 11%，两把尺子

- **教学目的**：让读者亲手看到，同一个期望回报，换一个预期回报模型，异常回报从 +2% 变成 −0.4%——联合假设问题的最小例子。
- **类型**：单柱 + 可切换的基准线（切换式交互）。
- **数据及来源**：教学假设，沿用 S05-03 的参数。无风险利率 4%，市场因子溢价 5%，价值因子溢价 3%；组合市场暴露 1.0、价值暴露 0.8、期望回报 11%。CAPM 正常回报 4% + 1.0 × 5% = 9%，异常回报 +2%；两因子模型正常回报 4% + 5% + 2.4% = 11.4%，异常回报 −0.4%。复算见《S06-02 数值核验.js》B 组。
- **逐步内容**：
  - 初始只显示 11% 的柱和两个按钮。
  - 按「CAPM」：在 9% 处画正常回报线，柱与线之间标「+2%，看上去战胜了市场」。
  - 按「两因子模型」：正常回报线由三段叠成（4%、5%、2.4%），合计 11.4%，柱顶低于线，标「−0.4%，扣掉价值暴露后没有」。
- **手机排版**：柱和线横向放置（横向条形），两按钮在上方并排；数字写在条形内或紧靠条形右侧。
- **静态版**：两行表（尺子｜正常回报｜异常回报｜结论）。
- **可访问性**：两按钮为单选组，键盘左右键切换；切换后 aria-live 读出「正常回报 9%，异常回报正 2%」等。

## 图 3　研究值不值得做

- **教学目的**：把信息成本悖论变成一个可以操作的均衡：研究者越多，每人分到越少；均衡人数由成本决定；成本越低，价格反映的信息越多，但只要成本大于零就不完全。噪声变多时人数增加、吸收比例不变。
- **类型**：曲线与水平线求交点，带按钮切换参数。
- **数据及来源**：教学模型，参数全部为假设，不是格罗斯曼与斯蒂格利茨的模型。没有人研究时的错价利润 A = 120 万元（「噪声变多」时 180 万元）；每多一位知情交易者利润缩小 b = 2 万元；研究成本 c = 1、2、4 万元。每人分到 (A − bn) ÷ n；均衡 n* = A ÷ (b + c)；价格吸收的信息 = bn* ÷ A = b ÷ (b + c)。
  - c = 1：n* = 40，吸收 2/3（约 67%）
  - c = 2：n* = 30，吸收 1/2
  - c = 4：n* = 20，吸收 1/3（约 33%）
  - A = 180，c = 2：n* = 45，吸收 1/2
  - 小题 3：c = 3，n* = 24，吸收 40%
  - 课文正文另举 n = 10（每人 10 万元）、n = 40（每人 1 万元）两点。
  复算见《S06-02 数值核验.js》C 组。方向与 Grossman–Stiglitz（1980）pp.399–401 的比较静态与定理 5 一致（S0602-R03），图下注明「教学模型」。
- **逐步内容**：
  - 初始：横轴 0–60 人，纵轴 0–12 万元；画出 (120 − 2n) ÷ n 曲线（n 从 5 起画，避免 n 趋于 0 时无穷大）与 c = 2 的水平线，交点 30 人，标「价格吸收一半信息」。
  - 成本按钮 1 / 2 / 4：水平线上下移动，交点依次为 40 / 30 / 20 人，旁标约三分之二 / 一半 / 三分之一。
  - 「噪声变多」开关：曲线换成 (180 − 2n) ÷ n，横轴扩到 90，c = 2 时交点 45 人，吸收仍为一半；旁注「人数变多，价格所含信息不变」。
- **手机排版**：图宽占满屏，按钮放在图下方两行；交点读数放在图上方的一行数字条里，避免与曲线重叠。
- **静态版**：四行表（情形｜成本｜均衡人数｜价格吸收的信息）。
- **可访问性**：按钮可键盘操作；每次切换后 aria-live 读出「成本 4 万元，均衡 20 人，价格吸收三分之一的信息」。曲线另提供一张 n = 10、20、30、40、60 的数值表。

## 图 4　价格错了 20%，下个月却几乎猜不出

- **教学目的**：直观显示「难以预测」与「价格正确」不是一回事：价格高估 20%、偏离缓慢消退时，短期可预测的部分远小于随机波动；看得越远，可预测的部分越大，但随机部分也在累积。
- **类型**：三组分步对比柱。
- **数据及来源**：教学模型，参数全部为假设。初始高估 20%；偏离每月保留 98%；随机波动每月约 5%，各月互不相关。
  - 1 个月：预期修正 20% × (1 − 0.98) = 0.4 个百分点；随机波动 5%；比值 12.5（「12 倍多」）
  - 1 年：20% × (1 − 0.98¹²) ≈ 4.3 个百分点；随机波动 5% × √12 ≈ 17.3%
  - 5 年：20% × (1 − 0.98⁶⁰) ≈ 14.0 个百分点；随机波动 5% × √60 ≈ 38.7%
  复算见《S06-02 数值核验.js》D 组。
- **逐步内容**：
  1. 只显示「1 个月」：浅色柱 0.4、深色柱 5，标「12 倍多」。
  2. 加上「1 年」：4.3 与 17.3。
  3. 加上「5 年」：14.0 与 38.7，并出现一行字「看得越远，可以预测的部分越大，但随机的部分也在累积」。
- **手机排版**：三组柱改为竖向排列的三行横向条形，每行两根条，数字写在条形末端。
- **静态版**：三行表（期限｜可以预测的修正｜随机波动的典型幅度）。
- **可访问性**：分步按钮可键盘操作；每步 aria-live 读出两根柱的数值。深浅两色另以斜纹区分，不只靠颜色。
