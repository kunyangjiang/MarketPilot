# 课程开场视觉规范

> 内部文档，不进入发布目录。2026-11-17 起适用于此后每一课的开场。

## 1. 原则

- **不要求每课一张照片。** 开场形式按这一课手里的证据、讲的机制、需要的画面来选。
- 找不到来源清楚、和本课相关的照片时，**换形式**，不硬配一张。
- 无论哪种形式，开场的日期、数字、首段文字都要准确、可读，桌面和手机都要检查。
- 沿用 J + Q 的版式：墨色是事实，紫色是压力或辅助，lime 只给当前一步，虚线是记录或公告；不用红涨绿跌。

## 2. 四种开场形式

| 形式 | 适用 | 例子 |
|---|---|---|
| **A. 档案照片** | 有真实场景、来源清楚的历史照片，能交代「那时那地」的氛围 | S02-02 路边市场（1916）；S09-03 华尔街人群（1907，馆藏推定） |
| **B. 文字排版叙事** | 事件或概念没有可靠的画面，但有清楚的日期、数字、一句话 | 大号日期 + 三个数字 + 一句来源 |
| **C. 历史物件与文件** | 机制本身体现在纸面上：票据、股票凭证、银行券、报价单、报纸版面、版画 | 一张旧票据的局部，配说明 |
| **D. 原创教学图** | 机制比场景重要，画面本身就是第一步讲解 | 订单簿、资产负债表、利率曲线的开场图 |

选择顺序没有优先级。一课只用一种主形式；B 可以叠在 A 或 C 上（照片或物件铺底，文字压在暗部）。

## 3. 照片和物件必须记录的信息

每一张照片或物件，在内部权利记录（`docs/照片来源与权利记录.md`）里写清：

1. **原始馆藏或出处**：机构、条目链接、编号（Image ID、LCCN 等）；
2. **作者**：不详就写「不详」；
3. **日期与不确定性**：馆藏推定、约数、范围都照原样标注；
4. **权利说明**：照抄原始记录的说明（例如 NYPL 的「无法确定」、LOC 的「No known restrictions」），以及我们是否已逐页核对；
5. **需要的署名**：读者页面上的照片说明和页脚来源怎么写。

读者页面只写来源和日期，**不写**「待核实」「版权未定」之类的状态标签；权利疑问只留在内部记录里，由 PO 在公开发布前决定。

## 4. 禁止事项

- **不编造来源信息。** 查不到的作者、日期、编号就写「不详」或「推定」，不补猜测。
- **不把照片说成它没有拍到的事件。** 例如 1907 年人群照不能说成 10 月 22 日尼克博克挤兑的现场。
- **不把合成图像当成历史记录。** AI 生成或重绘的图像不得以档案照片或历史文件的面目出现；原创示意图（形式 D）必须一眼能看出是图解。
- **不声称权利已清**，除非原始记录明确写明。
- 不绕过网站的访问限制或人机验证去取图或核对。

## 5. 上线前检查

- 照片能加载，有描述画面的替代文字，替代文字不指认具体事件；
- 照片说明与页脚来源一致，链接到原始馆藏条目；
- 文字压在照片暗部，桌面 1280 和手机 390 都可读，说明文字不挡正文；
- 测试里有对应断言（参照 `site/tests/s0903-content.test.js`、`s0903-browser.test.js` 的开场测试）。
