## 2. 路由结构

所有链接都是相对路径。站点部署在域名根目录或子路径下都能用。

| 地址（相对站点根） | 内容 |
|---|---|
| `./`、`./#home` | 首页 |
| `./#courses` | 课程目录 |
| `./#layer-1` … `./#layer-4` | 某一层 |
| `./#S01` … `./#S11` | 某一阶段（自动展开） |
| `./#S02-02` 等 61 个课号 | 这一课在目录中的那一行（会标出来） |
| `./#stories` | 故事（筹备中） |
| `./?search=词` | 打开搜索 |
| `lessons/S02-02/`、`lessons/S09-03/` | 两节课，是唯一的正式课程页 |

**两课之间的导航**
- 课程页面包屑：「课程」→ `../../#courses`，层级 → `../../#layer-N`，阶段 → `../../#S02` 或 `#S09`。
- 页头：logo 和「首页」→ `../../`；「课程」「故事」→ 对应栏目；「搜索」→ `../../?search=`。
- 从目录打开一课前，地址先换成该课所在的阶段，所以按浏览器"返回"会回到这个阶段。

**旧地址已全部停用。** 样稿里的 `#lesson`（S02-02 v2）、`#preview`、`#panel`（S09-03 预览）、`#story`、`#about`、`#sources` 都不再出现，站内没有任何链接指向 `design-exploration/` 或 `proto-v4/`。

## 4. 搜索索引

- **来源。** 生成脚本只读两课正式页面的读者可见正文：开场的标题、核心问题、学习目标，加上 `<article>` 里每个带 id 的小节。共 28 条，每课 1 条课程条目，S02-02 另有 12 个小节，S09-03 另有 14 个小节。结果链接到 `lessons/<课号>/#<小节>`。
- **不收的内容。** 课文原稿、核验记录、交互方案、样稿里过期的 S02-02 v2 文字，以及带 `hidden` 属性的元素。小题的提示和答案、沙盘的揭晓区都属于后者，不收是为了不让搜索摘要提前透露答案（这是本轮发现并修正的问题）。
- **筹备中的 59 课。** 只按「课号＋标题」收录，标「筹备中，暂不能阅读」，没有摘要，排在可阅读结果之后；选中后只定位到目录里的那一行。
- **筛选与提示。** 筛选按钮是「全部 / 可阅读 / 筹备中」。空状态的说明写明「可阅读的 2 课搜索全文；筹备中的 59 课只搜标题」。
- **保持更新。** 课程页改动后要运行 `node site/tools/build-search-index.js`。`site-search.test.js` 会重新生成一遍，和磁盘上的索引逐字比较，索引过期测试就失败。

## 5. 修正的导航问题

1. **首页、目录、搜索都进不了正式课程页。** 现在三处都直达 `lessons/<课号>/`。
2. **课程页依赖 `design-exploration/` 才能导航。** 已改为指向站点外壳。
3. **「跳到层级」无效。** 原因是样稿只在 `hashchange` 时滚动，而按钮的 href 都是 `#courses`。现在按钮是真正的锚点 `#layer-N`，并按吸顶跳转条的高度留出位置，目标不会被挡住。手机上跳转条改为单行横向滚动，原来会折成四行，占掉约 170px 高度。
4. **面包屑和"返回"只能回到目录顶部。** 现在回到该课所在的阶段。
5. **搜索收的是过期文字。** 现在只收正式课程页正文。
6. **页脚有「关于」「来源与方法」两个空页面的链接。** 已删除。本阶段不做这两页，课内的参考文献、来源说明、模型假设都保持原样。
7. **故事页是占位卡片。** 现在是纯文字的「筹备中」页，没有照片、封面、篇名或简介，也没有把 S09-03 当作故事。
8. **样稿没有网站图标，请求 404。** 外壳已加上和课程页相同的图标。
9. **「跳到正文」会把页面切回首页。** 现在只移动焦点，不改地址。
10. **`?search=` 留在地址里。** 打开搜索后从地址里去掉，刷新时不会再弹出。

## 8. 发布前仍有的问题

1. **发布目录里有开发文件。** `site/tests/`、`site/tools/`、`site/shots/`（约 34 MB 截图）都在 `site/` 里。Cloudflare Pages 会把整个目录发布出去，需要先决定怎么排除：把它们移出 `site/`，或者用一个只含网站文件的输出目录。
2. **照片热链。** 所有照片都直接热链 `upload.wikimedia.org`，正式发布前应改为放在本站。
3. **照片授权。** 第三层的横幅（1929 年交易所外人群，美联社）在 Commons 标为公有领域，本站没有另行核实（◐）。首页的金枪鱼拍卖是 2014 年的彩色照片，属于样稿中已经认可的例外，与「只用老照片」的方向不完全一致。这两处请 PO 确认。
4. **`noindex`。** 所有页面都带 `<meta name="robots" content="noindex">`，上线时要去掉。
5. **托管行为需在真实环境再核一次。** 目录地址补斜杠的规则在本地测试服务器上模拟过，部署后要在 Cloudflare 上复查。
6. **跨课依赖仍在。** S09-03 引用 `../S02-02/reader.js`，两课必须一起发布。
7. **没有真机测试，也没有逐页检查打印 PDF。**
8. **没有站点级的「关于」和「来源与方法」页面。** 这是本阶段的决定，以后是否补做由 PO 决定。
9. **课程页的状态标签。** 见第 3 节：已按 PO 早先的要求删除，本阶段没有恢复。
