## 1. 发布目录

**生成命令**

```bash
node site/tools/build-dist.js
```

- 输出到 `E:\MarketPilot\dist\`，每次清空后重建。不依赖任何 npm 包，也不用框架。
- 脚本步骤：
  1. 重新生成搜索索引；
  2. 从 `index.html` 和每节可阅读的课出发，顺着站内 `href` / `src` 收集文件；
  3. 原样复制，打印每个文件的 sha256 和总哈希。
- **源目录不会被删除或改写**，搜索索引除外，它本来就是生成文件。

### 2.3 判断

**`crowd29c`**
- 1929 年在美国发表的照片，如果当时没有合规的版权声明或没有续展，可能已进入公有领域。可是：

- 这两点都证明不了公有领域。AP 的商业授权说明权利方仍在主张权利。

**`tuna`**：版权没有问题，但不符合照片方向。这是风格问题，替换与否由 PO 决定。

**`abbottRoof` / `abbottSkyline` / `chicagoTrains`**：大概率没有问题，需要有人在浏览器里打开 NYPL 和 LOC 的页面，确认权利说明。我没有对 LOC 的验证页做任何绕过。

**部署前无法在本地确认的 Cloudflare Pages 行为**

1. 是否把 `/index.html` 和 `/lessons/S02-02/index.html` 308 重定向到不带 `index.html` 的地址。不影响功能，相对路径都成立。
2. 不带斜杠的目录地址，它用的状态码是 308 还是 301，以及是否保留 `?search=`。课程页的搜索按钮用的是 `../../?search=`，指向根目录，不受影响。
3. **没有 `404.html` 时，Pages 会把未知路径当单页应用处理，返回首页并给 200**。所以错误地址会显示首页，而不是 404。是否加 404 页由 PO 决定，本阶段没有加。
4. noindex 现在只靠每页的 `<meta name="robots">`。如果要连同脚本和样式一起挡住搜索引擎，可以加一个 `_headers` 文件，写 `X-Robots-Tag: noindex`。需要先在 Pages 上验证，本阶段没有加。
5. 字体和照片来自外网，部署后的加载情况与本地相同，但不受 Pages 控制。
