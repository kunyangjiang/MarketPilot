## 搜索

- 打开方式：
  - 页头按钮
  - Ctrl K / ⌘ K（再按一次关闭）
  - Esc 关闭，焦点回到打开前的位置
- 原生 `<dialog>` 模态，自带焦点限制。
- 键盘操作：
  - ↑ ↓ 选择，Enter 打开。
  - 输入框是 `combobox`，结果是 `listbox`，用 `aria-activedescendant` 标出当前项。
  - 结果数量通过 `aria-live` 播报。
- 筛选：全部 / 课程 / 故事，带计数。
- 每条结果有类型标签、标题、位置和摘录，命中的词高亮。
- 三种状态：
  - 空状态：说明和推荐词。
  - 无结果：给出建议。如果当前筛选没有结果、但"全部"里有，会提示切换。
- 索引是页面内的轻量静态数组，只收已发布的 S02-02（标题、11 节、正文、图 1、互动）和预览的 S09-03。故事条目全部标为"占位"。59 节未发布课程不进索引。
- 手机上全屏显示。
